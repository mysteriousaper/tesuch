  5. ԻՐԱՎԱԿԱՆ ԱԿՏԵՐ

  1. Տվյալ ստուգաթերթը կազմվել է հետևյալ նորմատիվ իրավական ակտերի հիման վրա՝

1)  «Բնակչության բժշկական օգնության և սպասարկման մասին» օրենք.

2)  Կառավարության 2002 թվականի հունիսի 29-ի N 867 որոշում.

3)  Կառավարության 2004 թվականի ապրիլի 8-ի N 539-Ն որոշում.

4)  Կառավարության.2011 թվականի հուլիսի 14-ի N 1024-Ն որոշում.

5)  Կառավարության 2014 թվականի սեպտեմբերի 4-ի N 952-Ն որոշում.

6)  Առողջապահության նախարարի 2021 թվականի դեկտեմբերի 06-ի N 88-Ն հրաման.

7)  Առողջապահության նախարարի 2008 թվականի սեպտեմբերի 24-ի N 17-Ն հրաման.

8)  Աշխատանքի և սոցիալական հարցերի նախարարի 2008 թվականի օգոստոսի 7-ի N-14-Ն և Առողջապահության նախարարի 2008 թվականի օգոստոսի 11-ի N-109-Ն համատեղ հրաման.

9)  Առողջապահության նախարարի 2007 թվականի նոյեմբերի 26-ի N 1752-Ն հրաման.

10) Առողջապահության նախարարի 2014 թվականի մայիսի 6-ի N 16-Ն հրաման.

11) Առողջապահության նախարարի 2006 թվականի սեպտեմբերի 22-ի N 1075-Ն հրաման.

12) Առողջապահության նախարարի 2022 թվականի հոկտեմբերի 25-ի N 72-Ն հրաման․

13) Առողջապահության նախարարի 2021 թվականի ապրիլի 15-ի N 21-Ն հրաման․

14) Էկոնոմիկայի նախարարի 2013 թվականի սեպտեմբերի 19-ի N 871-Ն հրամանի հավելված։
